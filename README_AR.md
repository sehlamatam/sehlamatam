# موقع مأتم سهل ماتم

## الملفات
- `index.html`: صفحة الموقع الحالية.

## تنبيه أمني مهم
لوحة الإدارة الموجودة في هذه النسخة تجريبية فقط؛ تحفظ كلمة المرور والمحتوى داخل متصفح الزائر باستخدام `localStorage`.
لا تستخدمها كلوحة إدارة عامة ولا تضع فيها بيانات سرية.

## الخطوة التالية
قبل تفعيل لوحة إدارة حقيقية باسم مستخدم وكلمة مرور، يجب إعداد خدمة خلفية للمصادقة وقاعدة بيانات وتخزين الملفات، ثم ضبط صلاحيات الوصول من جهة الخادم. رفع `index.html` وحده لا ينشئ حماية حقيقية.
